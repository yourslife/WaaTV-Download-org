Cara Install di Android

  1. Klik tombol Download APK Sekarang dan tunggu file selesai terunduh.
  2. Buka file .apk dari notifikasi atau folder Download.
  3. Jika muncul peringatan keamanan, izinkan Instal aplikasi tidak dikenal untuk browser/file manager kamu.
  4. Selesaikan instalasi lalu buka aplikasinya.
